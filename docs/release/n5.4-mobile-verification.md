# N5.4 mobile verification

N5.4 hardens the existing Astra chat workspace without changing the HTTP or
Socket.IO contract. Identity, conversation type, capabilities and all queue or
conversation transitions remain server-authoritative.

## Layout acceptance

- The app uses the dynamic viewport height with a small-viewport fallback, so
  browser chrome and a reduced software-keyboard viewport do not push the
  composer outside the visible workspace.
- Topbar, composer, drawers and chat modals include the applicable safe-area
  insets. Drawer and modal close controls expose at least a `44×44` target.
- The message list remains the only scrolling conversation surface. The joined
  message field and Send control remain usable without horizontal page overflow;
  the separate text-only Next action remains visible in random chat.
- Short landscape viewports reduce only non-interactive vertical padding. They
  do not remove actions, shrink touch targets or change conversation behavior.

## Automated viewport evidence

`test/browser/chat-desktop.spec.js` exercises the live chat at `1366×768`,
`1366×640`, `768×1024`, `390×844`, `844×390` and a reduced `390×520`
keyboard viewport. It verifies containment, message scrolling, input usability,
focus visibility, drawer/modal containment and touch targets, and captures the
corresponding screenshots.

`test/browser/social-surfaces.spec.js` additionally captures the Friends and
Chat requests drawers at `844×390`, alongside the existing desktop, tablet and
`390×844` evidence.

## Staging check

Open `/chat` in an authenticated account and in a guest session. At `390×844`,
focus the message field with the device keyboard open, send a message, use the
two-step Next confirmation in a random chat, and open/close Messages, Friends,
Notifications and Report using keyboard and touch. Rotate to landscape and
confirm that all controls remain reachable, the page does not scroll
horizontally, drawer content scrolls independently and the active conversation
does not change merely because the viewport changed.
